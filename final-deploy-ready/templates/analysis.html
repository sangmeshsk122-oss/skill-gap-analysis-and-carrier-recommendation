Recommendation Algorithm Documentation & Scope

Methodology: Career recommendations are computed using a deterministic, rule-based Weighted Competency Matching Engine rather than a black-box neural network. For each target career, required competencies are assigned target levels (1–5) and domain importance weights. Individual skill gaps are calculated strictly via Gap = max(0, Required_Proficiency - Current_Proficiency). Overall compatibility uses quiz-based normalized skill attainment, with a capped 0.2 attainment bonus when a required skill is listed among a student's project technologies. This bonus affects the match score only; it does not change quiz proficiency, skill gaps, or proficiency status.

Limitations: Project technologies are student-reported and are not independently verified, so portfolio evidence is supporting context rather than proof of proficiency. Evaluations use predefined industry benchmark weights configured by system administrators and do not account for geographical job market fluctuations or live employer hiring signals.
